# 逆向模式汇编打桩速查字典

> 来源：softseep 主控 §二 | 加载时机：需要具体汇编打桩指令模式时


| 目标场景 | 机器码序列 | 汇编指令 | 适用场景与安全特性 |
| :--- | :--- | :--- | :--- |
| **虚函数整型返回 1** | `b0 01 c3` | `mov al, 1; ret` | 3 字节，零栈破坏，适合 UI 判决虚函数 |
| **通用函数整型返回 1** | `b8 01 00 00 00 c3` | `mov eax, 1; ret` | 6 字节，清空高位，适合标准 Cdecl/Fastcall 标量接口 |
| **永久有效时间戳** | `b8 7f e6 85 f4` | `mov eax, 0xf485e67f` | 5 字节，硬件清零 RAX 高位，返回 2099-12-31 |
| **条件跳转强制直通** | `90 90` / `eb <disp>` | `nop; nop` / `jmp short` | 2 字节，消除校验失败跳转 |
| **长跳转跳过逻辑块** | `e9 <disp32> 90` | `jmp near <target>; nop` | 5~6 字节，跳过弹窗、试用拦截或广告拉取 |
| **BSTR 截断绕过** | `ff 25 [disp32]` | `jmp qword ptr [SysAllocString]` | 尾调用 IAT，自平衡栈且无 Double Free |
| **IAT 输出 API 挂钩** | 改写 IAT 槽位指针 | `*slot = Hook_Proc` | 零字节落盘、零 ABI 风险，适用显示层文案伪造 |
| **IAT 槽位恢复** | `*slot = realProc` | `VirtualProtect` + 回写 | 卸载钩子 / 规避自检，需先缓存原地址 |
| **整数比较强制置位** | `c7 45 fc 01 00 00 00 90 90 90` | `mov dword ptr [ebp-4], 1; nop*3` | **10 字节，替代 `cmp [ebp-x],0` + `je fail`**；比改 `je` 为 `jmp` 更语义化，且同长度覆盖不破坏指令对齐 |
| **条件跳转升级为无条件跳转** | `0f 8d <disp32>` → `e9 <disp32'> 90` | `jge target` → `jmp target; nop` | **6 字节等长改写**，`disp32' = disp32 + 1`（因多耗 1 字节）；适用于授权心跳/复检的本地裁决点 |
| **函数整体跳过（慎用）** | `c3` | `ret` | ⚠️ **高危**：会跳过函数体内的必要初始化，常导致**延迟崩溃**（本案例实测：改 `ret` 后约 17 秒才访问违例）。优先改判条件跳转 |
| **类型不匹配的假返回值（禁用）** | `b8 01 00 00 00 c3` | `mov eax,1; ret` | ⚠️ **禁用场景**：若原函数返回**字节集/文本**（如易语言支持库函数），强返整数会破坏后续类型转换调用 → 应立即改为“改判比较/跳转” |

### 补丁选型决策表（按“改动对象”分层）

> 授权旁路的优先级：**改判比较/跳转 > 改全局标志位 > 改返回值 > 跳过函数体**。

| 优先级 | 改动对象 | 风险 | 适用 |
| :---: | :--- | :--- | :--- |
| 1 | **条件跳转 / 比较指令** | 最低 | 本地裁决点（`cmp`+`je/jge`）—— 本案例 P1/P2/P3 均属此层 |
| 2 | **全局状态标志位**（`mov dword [g_state], 1`） | 低 | 存在“已授权”全局标志（如 `0x922C18`）时 |
| 3 | **函数返回值** | 中 | 仅当原函数确定返回标量（`BOOL`/`int`）时可用 |
| 4 | **函数体整体 `ret`** | 高 | 仅用于**纯阻塞型**函数（如看门狗 `Sleep` 循环），且需验证无初始化副作用 |
