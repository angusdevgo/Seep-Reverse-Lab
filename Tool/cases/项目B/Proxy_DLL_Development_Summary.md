# 项目B 模拟器代理 DLL 劫持与本地化去广告交付清单

## 1. 核心架构设计

在不破坏 `项目B.exe` 官方 Authenticode 数字签名的前提下，基于 Windows 动态链接库搜索与导出转发技术，开发了专用的 **`sentry.dll` 代理劫持与运行时内存热补丁体系**：

```
[项目B.exe]
       │
       ▼ (动态加载主目录 sentry.dll)
┌────────────────────────────────────────────────────────┐
│  代理 sentry.dll (由 ziglang/clang 编译的原生 x64 DLL)   │
├────────────────────────────────────────────────────────┤
│ 1. 169 个标准 sentry_* 接口全量透明转发 -> sentry_orig.dll│
│ 2. DllMain 注入看门狗线程                              │
│ 3. 内存热补丁：自动化定位 项目B.exe 模块基址        │
│ 4. 运行时下发本地特权 (VIP/到期时间2099/去广告/阻断云控)  │
└────────────────────────────────────────────────────────┘
```
