# Agent Note: 代码虚拟化保护的三层分离还原

Status: implemented

## Problem

项目N v2.2.4.3 使用商业混淆器（Eazfuscator.NET）的**全保护模式**，
其中代码虚拟化把关键方法编译为自定义字节码，由内置解释器执行。

目标是从被保护的二进制中还原出**可读的方法表与字节码**，以便：
1. 定位授权判定逻辑在虚拟化层中的具体位置；
2. 评估"保护层强度"与"架构缺陷"之间的关系（本案例的核心论点）。

难点：虚拟化数据不是单一封装，而是**多层嵌套**，且每层的算法都不同。
若把整体当成一个黑盒去爆破，成本不可接受。

## Decision

采用**逐层分离**策略：把虚拟化保护拆成三个可独立求解的子问题，
每层都用**运行时探针与离线复算交叉验证**，确认无误后再进入下一层。

三层结构（自外向内）：

1. **非对称封装层** —— RSA-2048 / PKCS#1 v1.5 逐块解密
   - 模数由两段拼成：FieldRva 数据段（128 B）‖ 内嵌 base64 字符串解码（128 B）
   - 块长 256 B，每块明文 245 B（PKCS#1 固定 8 字节填充）
   - 验证判据：**所有块都通过 PKCS#1 v1.5 校验，且填充长度恒为 8**
     —— 填充长度恒定即证明构建期采用了固定分块策略，而非通用 RSA 加密

2. **位置相关流加密层** —— 单字节 XOR
   - `plain[i] = cipher[i] ^ (byte)(seed ^ i)`
   - `seed = seedArg ^ (-559030707)`，keystream **只与偏移相关，与内容无关**
   - 验证判据：解密后熵由 7.9997 降至 6.7565，可打印串数量显著上升

3. **方法寻址层** —— 名称即自描述令牌
   - 令牌 → Ascii85 解码 → 流 XOR 解密 → 乱序 ReadInt64 → VM 流偏移
   - 验证判据：**运行时探针与离线复算逐条比对，7/7 精确命中**
   - 额外确认编码**完全可逆**（能逐字节复现原始令牌）

关键约束：**每层都必须有独立的客观验证判据**，不允许"看起来对"就进入下一层。
层与层之间的错误会级联放大，前一层错了后一层必然无解。

## Alternatives considered

- **把虚拟化整体当黑盒，直接对字节码做统计分析** ——
  最强理由：不需要理解任何一层算法，纯数据驱动，理论上适用于任意实现。
  否决原因：位置流加密让字节码的统计特征被完全抹平（熵接近 8.0），
  且没有已知明文参照，统计分析无着力点。实测无法推进。

- **直接反汇编虚拟机的解释器循环，还原指令集后再反编译字节码** ——
  最强理由：这是最"正统"的做法，一次投入可完整还原全部虚拟化方法，
  且能产出语义级结果。
  否决原因：解释器约 1.3 万行，含约 1000 个指令处理程序，
  操作码被随机化重排；这是一项独立的长期工程。
  在本案例中**先不做**：三层分离后已能拿到可读方法表与字节码，
  足以支撑"定位授权判定"与"评估保护强度"两个目标。
  ISA 还原作为后续可选工作保留。

- **对资源做通用压缩/编码探测（zlib / gzip / LZ4 / LZMA 等）** ——
  最强理由：成本极低，一行代码就能试完所有常见格式。
  否决原因：全部未命中；且熵分析已表明这不是通用压缩格式。

## Consequences

- **收益**：722,260 字节 VM 字节码被还原为可读明文，含 3,917 个成员记录与
  7,107 条可打印字符串（类型名、方法名、程序集引用全部可读）；
  授权判定逻辑在虚拟化层中的位置被精确定位。
- **收益**：建立了可复用的**三层分离方法论**——
  凡是"非对称封装 + 位置流加密 + 自描述令牌"这一组合的虚拟化实现，
  都可以按同样路径还原。
- **代价与已知上限**：本方案产出的是**方法表与字节码**，不是语义级反编译结果。
  若需要理解某个虚拟化方法的**具体逻辑**，仍需还原指令集。
  当出现以下信号时必须重访该决定：需要按语义修改虚拟化方法内部逻辑，
  或需要审计虚拟化层中的其它业务分支。
- **代价**：RSA 层只有公钥，**无法自行重加密**。
  若要修改 VM 字节码，必须走"替换公钥"路径（已在保护层文档中记录该路径所需的全部能力）。

## Verification

- 第 1 层：2948/2948 块通过 PKCS#1 v1.5，填充长度恒为 8；
  离线 `pow(c, e, n)` 结果与客户端运行时流**逐字节一致**。
- 第 2 层：解密前后熵 `7.9997 → 6.7565`；偏移 0 处直接出现程序集标识字符串。
- 第 3 层：7 组（令牌 → 偏移）样本，运行时探针与离线复算**全部一致**；
  编码器往返测试可逐字节复现原始令牌。
