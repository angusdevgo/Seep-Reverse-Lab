# 本工单授权范围（模板 · 请自己填）

> **这个文件是给你写的，不是给模型猜的。**
> 填了，lab 模式下会把它原样贴进上下文；不填（保持模板原样），就相当于没写，
> 模型只会看到「没有授权说明」。
>
> 原则：**有授权就照实写，没授权就不要编。** 编出来的授权比没有更糟 ——
> 它会让模型在一件真出事的事情上以为「这是被允许的」。

## 允许做什么

- [ ] 静态分析（反编译、字符串、控制流）
- [ ] 动态插桩（Frida / LSPosed），仅在自有设备
- [ ] 本地重打包与签名验证
- [ ] 内存转储与还原

## 不允许做什么

- [ ] 不得对外网服务发起请求
- [ ] 不得在非授权设备上运行
- [ ] 不得散布、转售、公开样本或 PoC
- [ ] 不得绕过第三方（云服务/支付/版权）的保护
